<h2 align="center">📌 Proyectos destacados</h2>

<p align="center"><strong>Desarrollos clave que demuestran arquitectura, lógica y resolución de problemas.</strong></p>

1. **Catálogo Digital de Recursos Web**
   * *Stack:* Nest.js, PostgreSQL, React.js, TailwindCSS.
   * *Logro:* Diseñé una arquitectura backend con una base de datos relacional de más de 26 tablas y desarrollé más de 30 endpoints RESTful validados.


2. **Sistema de Automatización Operativa**
   * *Stack:* n8n, Análisis de Requerimientos, Excel Avanzado.
   * *Logro:* Modelado de flujos de trabajo e integración de datos automatizados basados en reglas de negocio para optimizar el control operativo.
3. **📝 Notizen — Gestión de Notas Full-Stack**
   * *Stack:* Nest.js, PostgreSQL, React.js (Vite), TypeScript.
   * *Logro:* Implementé un flujo completo de operaciones CRUD con persistencia en base de datos relacional y una interfaz modular optimizada mediante Vite.
   * [Ver Repositorio](https://github.com/MatiasCarlsson/Notizen)
